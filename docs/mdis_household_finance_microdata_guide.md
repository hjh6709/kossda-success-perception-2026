# MDIS 가계금융복지조사 마이크로데이터 확보 가이드

## 목적

이 문서는 가계금융복지조사 마이크로데이터를 내려받아, 같은 가구 안에서 소득과 순자산의 관계를 확인하기 위한 준비 절차를 정리한다.

우리 프로젝트에서 이 자료는 메인 데이터가 아니다. 메인 데이터는 KGSS이며, 가계금융복지조사 마이크로데이터는 KGSS에서 나타난 성공 인식 변화를 이해하기 위한 경제적 배경 자료로 사용한다.

## 받아야 할 자료

MDIS에서 다음 자료를 확인한다.

- 조사명: 가계금융복지조사(2017년~)
- 우선 연도: 2025년
- 가능하면 비교 연도: 2021년, 2023년, 2025년
- 서비스: 다운로드 서비스 또는 원격접근 서비스

함께 받아야 할 파일은 다음과 같다.

- 마이크로데이터 원본
- 파일설계서
- 코드집
- 조사표
- 이용자 유의사항

## 필요한 변수

마이크로데이터를 받은 뒤 파일설계서에서 다음 변수명을 확인한다.

- 가구 식별 또는 행 단위 식별 변수
- 가구주 연령
- 가구소득
- 근로소득
- 순자산
- 자산
- 부채
- 가중치
- 주택 보유 여부 또는 거주주택 관련 변수

정확한 변수명은 파일설계서 확인 전까지 확정하지 않는다.

## 분석 목표

마이크로데이터로 확인하려는 질문은 다음과 같다.

1. 같은 가구 안에서 소득이 높은 가구는 순자산도 높은가?
2. 소득은 높지만 순자산은 낮은 가구는 어느 연령대에서 많이 나타나는가?
3. 순자산은 높지만 소득은 낮은 가구는 어느 연령대에서 많이 나타나는가?
4. 주택 보유 여부를 고려하면 소득과 순자산 관계가 어떻게 달라지는가?

## 저장 위치

원자료는 Git에 추가하지 않는다. 로컬에서만 다음 위치 중 하나에 둔다.

- `data/raw/household_finance_2025/`
- 또는 다운로드 폴더의 원래 위치

`data/raw/`는 `.gitignore`에 의해 Git 추적에서 제외되어 있다. 그래도 실수로 원자료를 commit하지 않도록 `git status`에서 원자료 파일이 보이지 않는지 확인한다.

## 저장 가능한 산출물

다음 파일만 저장한다.

- 분석 노트북
- 집계표 CSV
- 시각화 PNG
- 문서

저장하지 않는 파일은 다음과 같다.

- 원자료
- 개인/가구 단위 행이 남아 있는 processed data
- 마이크로데이터를 일부 추출한 CSV
- 재식별 가능한 표

## 해석상 주의

마이크로데이터를 사용하더라도 인과관계를 단정하지 않는다.

정확한 표현은 다음과 같다.

- 소득과 순자산은 같은 것이 아니다.
- 같은 가구 안에서도 소득 수준과 순자산 수준이 다를 수 있다.
- 순자산은 연령, 생애주기, 주택 보유, 상속·증여, 자산 축적 기간의 영향을 함께 받는다.
- 이 분석은 성공 인식 변화의 경제적 배경을 보조적으로 설명하는 역할을 한다.
