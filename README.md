# KOSSDA Success Perception Visualization 2026

## Project Overview

This repository contains analysis code and visualization materials for the KOSSDA University Student Data Visualization Competition 2026.

## Research Question

Can people still succeed through hard work in Korea, or has the perceived formula for success shifted toward family background, parental education, and social networks?

## Main Dataset

- Korean General Social Survey, 2003-2025 [Cumulative File]
- Provider: Korea Social Science Data Archive (KOSSDA)
- Producer: Survey Research Center, Sungkyunkwan University

## Supplementary Dataset

- Survey of Household Finances and Living Conditions
- Provider: MDIS / Statistics Korea

## Important Note

Restricted raw data files are not included in this repository.  
Please obtain the original datasets from the official data providers.
